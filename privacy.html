Privacy Policy

Last updated: October 29, 2026

About the Application

Hermes Google Tasks is a personal application that connects Google Tasks to a privately hosted AI assistant running on Synology NAS.

Data Access and Use

The application requests access to Google Tasks to read, create, update, complete, and delete tasks as instructed by the authorized user.

Data Storage

OAuth credentials and tokens are stored on the user's privately managed server. Task data may be processed locally to fulfill user requests.

Data Sharing

The application does not sell Google user data or share it with third parties for advertising. Task content may be sent to the AI service configured by the user when necessary to process requests.

Data Retention and Deletion

Locally stored credentials and task data can be deleted by the server owner. Access can also be revoked through Google Account settings.

Contact

For privacy questions, contact the application developer using the support email shown on the Google OAuth consent screen.
